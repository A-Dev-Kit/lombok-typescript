# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Please report security vulnerabilities privately via GitHub Security Advisories:

https://github.com/A-Dev-Kit/lombok-typescript/security/advisories/new

Do not open public issues for security reports.

We aim to acknowledge reports within 7 days.

## Dependency vulnerabilities

Dependabot monitors this repository for vulnerable dependencies. The Security tab may also list **OpenSSF Scorecard** governance findings (branch protection, code review policy, fuzzing, CII best practices). Those are repository posture checks, not npm package CVEs. Open Dependabot alerts for dependency CVEs are tracked separately under **Dependabot**.
